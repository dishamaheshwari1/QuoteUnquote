# QuoteUnquote

A beautiful, minimal quote journaling app for macOS. Capture the words that move you, organized in a clean, native interface.

## Installation

1. **Download:** Get the latest `QuoteUnquote.dmg` from the [Releases](https://github.com/dishamaheshwari1/QuoteUnquote/releases) page.
2. **Mount:** Double-click the downloaded DMG file.
3. **Install:** Drag the **QuoteUnquote** icon into the **Applications** folder shortcut.
4. **Clean up:** Eject the mounted "QuoteUnquote" installer from your Finder sidebar.
5. **Open:** Launch **QuoteUnquote** from your Applications folder.

### Security Note
Because this app is independently developed:
* If macOS blocks the app, go to **System Settings** → **Privacy & Security** and click **"Open Anyway"**.
* Alternatively, **Right-Click** the app in your Applications folder and select **Open**, then click **Open** again in the pop-up.

> **Important:** Do not run QuoteUnquote directly from the DMG. Automatic updates work best once the app is moved to your Applications folder.

## How to Use
* **Add Quotes:** Click the "+" button to save a new quote and its author.
* **Browse:** Scroll through your personal feed of inspiration.
* **Search:** Quickly find that one line you remember by searching authors or text.

## Receiving Updates
QuoteUnquote features built-in automatic updates. 
* The app will occasionally check for new versions in the background.
* You can manually check by going to the **QuoteUnquote** menu in the top Mac menu bar and selecting **Check for Updates...**
* When an update is found, it will download and install itself with a single click.
